# 阴影 Token

> 来源：token_shadow.png | 更新：2026-07-06  
> 所有阴影颜色基色均为 `#000000`，透明度通过 rgba 控制。

## Token 全表

| Token | CSS box-shadow 值 | 使用场景 |
|-------|-------------------|---------|
| `shadow_card` | `0 1px 5px 0 rgba(0,0,0,0.08)` | 卡片、轻量浮层 |
| `shadow_float` | `0 3px 8px 0 rgba(0,0,0,0.10)` | 悬浮按钮、置顶元素、顶部浮层 |
| `shadow_image` | `2px 2px 5px 0 rgba(0,0,0,0.12)` | 图片块、视觉卡片 |

---

## 参数明细

| Token | X偏移 | Y偏移 | 模糊(Blur) | 扩散(Spread) | 颜色 | 透明度 |
|-------|------:|------:|-----------:|-------------:|------|-------:|
| shadow_card | 0 | 1px | 5px | 0 | #000000 | 8% |
| shadow_float | 0 | 3px | 8px | 0 | #000000 | 10% |
| shadow_image | 2px | 2px | 5px | 0 | #000000 | 12% |

---

## 使用约束

- 同一页面阴影层级不超过 2 种，避免视觉混乱
- 卡片/列表项使用 `shadow_card`，悬浮操作按钮使用 `shadow_float`
- 图片卡片需要轻微立体感时使用 `shadow_image`
- 禁止对文字或图标直接添加阴影
- 禁止使用 Token 以外的自定义阴影值
